# Alif Urdu Emergency Response

Fine-tuned Alif 8B model for Pakistani emergency call handling with high-quality Urdu dataset generation pipeline.

## Overview

This project creates a specialized Urdu language model for Rescue 1122 emergency operators. The model handles medical emergencies, fires, accidents, and natural disasters in authentic Pakistani Urdu.

**Key Features:**
- Pure Urdu dataset (no English contamination)
- 99/100 quality score
- Fine-tuned Alif 8B model
- Automated dataset generation

## Quick Start

This project fine-tunes the Alif 8B model to help Pakistani emergency responders handle Urdu emergency calls. It uses a clean, high-quality Urdu dataset and a simple pipeline to generate realistic conversational scenarios for medical emergencies, fires, accidents, and natural disasters.

To try it, install dependencies from requirements.txt and run the pipeline with main.py to generate data and analyze quality. See main.py, generator.py, and analyze_conversational.py for the main steps; the repo includes examples and a fine-tuned model for quick inference.
